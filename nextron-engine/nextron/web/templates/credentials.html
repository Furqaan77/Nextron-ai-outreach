Unsubscribe token keys

Every unsubscribe link carries a token made with the two keys of one key id: k_tok encrypts it and k_edge tags it. New links use the key id set as Unsubscribe token key id (Settings, Sending). Make each key with uv run python -c "import secrets; print(secrets.token_urlsafe(32))" and paste it here; k_tok and k_edge must differ.

Escrow every k_tok: keep a copy off this PC, such as in a password manager or a sealed printout. Without it, the links already sent under its key id can't be read again.

Put every k_edge in the unsubscribe Worker too, as the secret K_EDGE_<kid> (K_EDGE_1 for key id 1). k_tok never goes there.

A key id's keys can't be replaced or removed while it has links under 2 years old.
